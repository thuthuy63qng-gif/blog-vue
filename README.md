# Ứng dụng quản lý trang blog

Dự án xây dựng bằng Vue 3 và Bootstrap theo yêu cầu bài tập Frontend.

## Chức năng

- Đăng ký, đăng nhập và đăng xuất.
- Đăng bài, xem danh sách, chỉnh sửa và xóa bài viết.
- Bình luận bài viết; chủ sở hữu có thể sửa hoặc xóa bình luận.
- Xem và chỉnh sửa hồ sơ: tên, email, mật khẩu và ảnh đại diện.
- Tìm kiếm, lọc chủ đề và sắp xếp bài viết.
- Bảo vệ các trang đăng bài, quản lý bài viết và hồ sơ bằng Vue Router.

## Công nghệ

- Vue 3 và Vue Router
- Bootstrap 5
- Vite
- `localStorage` để lưu tài khoản, bài viết và bình luận trên trình duyệt hiện tại

## Chạy dự án

```sh
npm install
npm run dev
```

Tạo bản build production bằng:

```sh
npm run build
```
